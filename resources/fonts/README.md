# Font ikon (Material Symbols)

`material-symbols-subset.woff2` adalah Material Symbols Outlined (weight 400, tanpa fill) yang
sudah dipangkas hanya berisi ikon yang dipakai. Font aslinya 4 MB, versi ini sekitar 7 KB.

Ikon yang tersedia: home, dashboard, grain, factory, inventory_2, point_of_sale, shopping_cart, receipt_long, group, local_shipping, person, mail, lock, visibility, visibility_off, arrow_forward, arrow_back, check, check_circle, close, error, warning, info, add, edit, delete, search, menu, logout, settings, account_circle, progress_activity, insights, payments, trending_up, trending_down, calendar_today, schedule, play_arrow, cancel, expand_more, chevron_right, more_vert, notifications, bar_chart, inventory, category, scale, science, thermostat, store, verified, verified_user, sensors, contactless, save, remove, more_horiz, account_balance, qr_code_2, filter_list, inbox, add_box, fact_check, receipt, history, play_circle, radio_button_unchecked, edit_note, undo, block, expand_less, calendar_month, account_balance_wallet, precision_manufacturing, remove_shopping_cart, storefront, shelves, person_off.

Kalau butuh ikon lain, ikon itu tidak akan tampil (yang muncul hanya teks namanya).
Minta ikon ditambahkan lalu font dibuat ulang dengan fonttools (pyftsubset).
